# بوت تحليل الذهب - التحليل الفني المتقدم

## 📋 نظرة عامة

بوت تليجرام احترافي لتحليل الذهب (XAUUSD) بدمج متقدم للمؤشرات الفنية وإدارة رأس المال.

### ✨ المميزات الرئيسية

✅ **تحليل فني متقدم:**
- 5 مؤشرات فنية: RSI, MACD, Bollinger Bands, EMA, Stochastic
- دمج ذكي للمؤشرات لتقليل نسبة الخطأ
- حساب نسبة الثقة للإشارة

✅ **إدارة رأس مال احترافية:**
- حساب حجم العقد بناءً على المخاطرة
- نسبة مخاطرة ثابتة: 3% من رأس المال
- حساب نقاط الدخول والخروج والأهداف

✅ **فريمات زمنية متعددة:**
- تحليل على فريم 1 دقيقة
- تحليل على فريم 5 دقائق
- تنبيهات عند الإشارات الجديدة

✅ **واجهة تليجرام سهلة:**
- أوامر بسيطة وسهلة الاستخدام
- رسائل منسقة وواضحة
- إشعارات فورية

## 📊 شرح المؤشرات الفنية المستخدمة

### 1️⃣ RSI (مؤشر القوة النسبية)
- **الفترة:** 14 شمعة
- **التشبع الشرائي:** > 70 (بيع)
- **التشبع البيعي:** < 30 (شراء)
- **الاستخدام:** قياس قوة الاتجاه والانعكاسات المحتملة

### 2️⃣ MACD (التقارب والتباعد)
- **الخطوط:** EMA12, EMA26, Signal Line
- **الإشارة:** تقاطع الخطوط
- **الاستخدام:** تأكيد الاتجاه والتغيرات

### 3️⃣ Bollinger Bands (العصابات)
- **الفترة:** 20 شمعة
- **الانحراف المعياري:** 2
- **الإشارة:** الخروج من الفرقة
- **الاستخدام:** تحديد الاختراقات والتقلبات

### 4️⃣ EMA (المتوسطات المتحركة الأسية)
- **السريع:** 20 شمعة
- **البطيء:** 50 شمعة
- **الإشارة:** التقاطع والاتجاه
- **الاستخدام:** تحديد الاتجاه العام

### 5️⃣ Stochastic Oscillator
- **الفترة:** 14 شمعة
- **التشبع الشرائي:** > 80
- **التشبع البيعي:** < 20
- **الاستخدام:** تأكيد الانعكاسات

## 💡 كيفية عمل دمج المؤشرات

البوت يجمع إشارات جميع المؤشرات ويحسب نسبة الاتفاق:

```
مثال:
- RSI: شراء ✓
- MACD: شراء ✓
- Bollinger: محايد
- EMA: شراء ✓
- Stochastic: شراء ✓

نسبة الاتفاق = 4 شراء من 5 = 80% ✓
إذا كانت النسبة >= 65% = إشارة شراء قوية
```

## 💰 إدارة رأس المال

### حساب حجم العقد:

```
Risk Amount = Account Balance × Risk% (3%)
Position Size = Risk Amount / (Entry Price - Stop Loss)
```

### مثال عملي:

```
الحساب: $250
المخاطرة: 3% = $7.50
سعر الدخول: $2050
وقف الخسارة: $2048

حجم العقد = $7.50 / ($2050 - $2048) = 3.75 Lot
```
